# Research Prompt Notes

The live prompt is generated inside CardTrack from the current active card catalog.

Open:

`CardTrack -> Admin Publisher -> Research Prompt`

The prompt:

- includes every active, non-archived card;
- requires live web research;
- prioritizes issuer sites and approved credit-card sources;
- separates public and targeted offers;
- classifies elevated and limited-time promotions;
- requires supported expiration dates;
- returns only schema-version-3 JSON;
- can be copied with one click.

After adding or restoring a card, reopen the prompt so the updated catalog is included.
