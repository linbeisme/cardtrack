# CardTrack v5.2.0 Release Notes

## Interface updates
- Dark, individually color-coded navigation tabs.
- Credit-card emoji favicon and browser-bookmark title.
- Distinct background shades for each Admin Publisher section.
- Clickable Current Offers KPI cards that filter the offer table.

## Transfer bonuses
- Active transfer-bonus rows now display a prominent expiration date plus remaining time.

## Fact sheets
- Offer-status badge appears in the upper-right corner of every fact-sheet card.
- All imported perks and benefits are displayed instead of truncating the list.
- Top and unique benefits appear first and receive visual labels.
- Card Facts prompt requests complete benefit inventories and top/unique metadata.

## Compatibility
- Existing fact data remains valid. New top/unique metadata is optional for legacy records.
