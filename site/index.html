Methodology and limitations

Promotion labels

Elevated means a public offer is above the card's stored baseline. Limited time is used only when research explicitly identifies a time-limited offer. The expiration date is displayed when a supported date is available. Targeted, referral, branch, and mailer offers are always separated from guaranteed public offers.

Source priority

  1. Official issuer application page or terms
  2. Doctor of Credit
  3. Frequent Miler
  4. One Mile at a Time
  5. The Points Guy
  6. NerdWallet

Data safety

Imported source URLs must use HTTPS and an approved domain. Expired offers and malformed records are rejected. A save is blocked when the database fails validation or contains zero imported offers after an attempted offer import.

Consumer notice

Welcome offers can be targeted, changed, or withdrawn without notice. Always verify the exact terms shown to you on the issuer's application page before applying.

CardTrack is an informational tool and is not affiliated with any card issuer. Never place your GitHub token inside a repository file.
